# Security Policy

## Supported versions

Only the latest released version of anki-activitywatch receives fixes. Please update to the newest release before reporting an issue.

## Reporting a vulnerability

Please report security issues privately rather than opening a public issue:

- Use GitHub's **"Report a vulnerability"** button (Security tab → Privately report a vulnerability): <https://github.com/jsglazer/anki-activitywatch/security/advisories/new>
- or open a regular issue **without** sensitive details and ask for a private channel.

Please include reproduction steps and the version you are running (see Tools → Add-ons). We aim to acknowledge reports within 14 days and to release a fix in a subsequent version.

## Scope

anki-activitywatch is an Anki add-on. It runs inside Anki with full access to your collection. Report anything that could expose or corrupt collection data, or let untrusted content execute code.
